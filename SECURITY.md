# Security policy

## Supported versions

Security fixes apply to the latest release.

## Reporting a vulnerability

Report vulnerabilities through GitHub Security Advisories instead of a public issue.

Include:

- A description of the vulnerability
- Steps to reproduce it
- Its expected impact
- A suggested fix, when available

## Data handling

Reef observes processes and commands to classify resource usage. It must not persist complete command lines, environment variables, file contents, credentials, or tokens by default.
